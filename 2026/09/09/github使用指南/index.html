github使用指南

观前提示：首先你的电脑上已经安装了Git，最好拥有魔法工具，为了方便还需要GitHub Desktop（在网络不稳定时使用其推送/拉取）

1.怎么将GitHub仓库克隆到本地
1.1 将该仓库的网址复制下来，(e.g. https://github.com/Pa1nKil1er/Pa1nKil1er.github.io)
1.2 打开git，
git clone (把上面的url粘贴下来)
我的git默认是在desktop，所以会直接在桌面看到仓库文件夹
or
1.3 GitHub Desktop：菜单栏 File -> Clone Repository。在弹出的窗口中，可以看到你的GitHub上的仓库列表，选中你想要克隆的仓库，然后选择本地保存路径，点击Clone即可
